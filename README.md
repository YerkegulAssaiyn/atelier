# Поиск помещения под ателье в Астане

Каждый день (в 08:00 по Астане) скрипт проверяет новые объявления об аренде
коммерческих помещений в Астане до 150 000 ₸/мес на **Krisha.kz** и **OLX.kz**
и присылает только новые варианты в Telegram.

## Шаг 1. Создать Telegram-бота

1. В Telegram найди **@BotFather**, напиши `/newbot`.
2. Придумай имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — это `TELEGRAM_BOT_TOKEN`.
4. Напиши своему новому боту в Telegram что угодно, например "привет"
   (это нужно, чтобы бот увидел твой чат).
5. Открой в браузере (подставив свой токен):
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
6. В ответе (JSON) найди `"chat":{"id": ЧИСЛО, ...}` — это твой `TELEGRAM_CHAT_ID`.

## Шаг 2. Создать репозиторий на GitHub

1. На github.com нажми **New repository**, например назови `atelier-astana`.
   Сделай его **приватным** (Private) — там будет твой Telegram-токен в секретах.
2. Залей туда все файлы из этой папки (можно перетащить в веб-интерфейсе
   GitHub через "Add file → Upload files", либо через git).

## Шаг 3. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_CHAT_ID` — chat id из шага 1

## Шаг 4. Включить Actions

Перейди во вкладку **Actions** репозитория, подтверди включение workflow
("I understand my workflows, go ahead and enable them").

Дальше скрипт будет запускаться сам каждый день в 08:00 (Астана).
Проверить сразу, не дожидаясь завтра, можно вручную:
**Actions → Поиск помещения под ателье → Run workflow**.

## Настройки

Открой `search.py`, в начале файла:

```python
BUDGET_MAX = 150_000   # максимальный бюджет аренды, тг/мес
MAX_KRISHA_PAGES = 5   # сколько страниц Krisha просматривать за раз
```

Меняй под себя и коммить изменения — на следующий запуск подхватится
новое значение.

## Важно про Instagram/Threads

У них нет открытого API/поиска объявлений по гео и ключевым словам, поэтому
автоматически они сюда не включены. Рекомендация: подпишись вручную на
2–3 паблика вида "сдам/сниму помещение Астана" в Instagram и включи для них
уведомления в самом приложении.

## Если сайты изменят вёрстку

Скрипты парсят HTML-структуру Krisha.kz и OLX.kz по состоянию на август 2026.
Если сайты обновят дизайн, парсер может перестать находить объявления —
в таком случае просто напиши мне, пришлю обновлённую версию.
